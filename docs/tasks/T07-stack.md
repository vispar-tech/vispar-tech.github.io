# T07 — Stack: визуальные группы

## Цель
Секция стека: шесть групп технологий, сканируемых взглядом за секунды.

## Вход
Контент: `stack.groups[]` обоих языков. Заглушка `Stack.astro`.

## Шаги
1. Названия групп моноширинным uppercase (уже есть) — проверить ритм сетки.
2. Чипы: консистентная высота; длинные значения («event-driven architecture») не ломают
   сетку — переносить целиком.
3. Опционально: сгруппировать визуально «core» (Python/FastAPI/Rust) сильнее остальных —
   только средствами веса шрифта/цвета, без новых секций.

## Критерии приёмки
- Сетка ровная на 375px (1 колонка), ~768px (2 колонки), 1280px (3 колонки).
- Никакого текста вне контент-файлов.
- `npm run build` + `npm run check` зелёные; скриншоты.

## Идеи вне скоупа
- Прогресс-бары навыков, проценты, рейтинги.

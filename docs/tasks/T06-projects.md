# T06 — Projects: метаданные репо

## Цель
Карточки репо довести до состояния «хочется кликнуть»: цветная точка языка, звёзды,
аккуратные ховер-состояния.

## Вход
- Контент: `projects.items[]`; звёзды приходят build-time через `src/lib/github.ts`.
- Заглушка `Projects.astro` с TODO(T06).

## Шаги
1. Цветная точка языка перед названием языка (Python/Rust/TypeScript — общепринятые цвета
   GitHub Linguist; добавить как токены `--lang-python` и т.п. в tokens.scss).
2. Звёзды: если API вернул — показать; если нет (fallback) — просто не рендерить счётчик.
   Формат: `★ 12` моноширинным, приглушённо.
3. Ховер: уже есть подъём и рамка акцентом — проверить, что не дёргается на тач-устройствах
   (`@media (hover:hover)` для transform).
4. Ссылка «Все репозитории» остаётся внизу сетки.

## Критерии приёмки
- При недоступном API сборка не падает, карточки рендерятся из статики.
- Точки языков видны, цвета различимы на тёмном фоне.
- `npm run build` + `npm run check` зелёные; скриншоты.

## Идеи вне скоупа
- Живые данные в браузере, спарклайны коммитов, скриншоты репо.

# T08 — Contacts + Footer

## Цель
Финализировать контактную секцию и подвал: понятные цели ссылок, порядок, финальный ритм.

## Вход
Контент: `contacts` обоих языков. Заглушки `Contacts.astro`, `Footer.astro`.

## Шаги
1. Карточки контактов: проверить контраст подписей (`--text-muted` на `--element`) по AA;
   при необходимости поднять до `--text-secondary`.
2. Email-карточка: длинный адрес не ломает сетку (`overflow-wrap: anywhere` уже стоит).
3. Подвал: год актуальный (уже динамический), локация моноширинным, ссылки в ряд.
4. Проверить tab-порядок: секция → карточки → подвал без прыжков.

## Критерии приёмки
- Все три контакта читаемы и кликабельны на 375px; mailto/t.me/github открываются корректно.
- `npm run build` + `npm run check` зелёные; скриншоты.

## Идеи вне скоупа
- Форма обратной связи (нужен бэкенд), QR-коды.

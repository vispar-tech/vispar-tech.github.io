# T05 — Experience: карточки опыта

## Цель
Две карточки опыта (JustDo CRM/WMS, Сагиров/JCrypto): читаемая структура, период,
буллеты, стековые чипы.

## Вход
Контент: `experience.items[]` в обоих языках. Текущая заглушка `Experience.astro`.

## Шаги
1. Иерархия в карточке: компания (сильный акцент) → роль моноширинным → период справа.
2. Период: выравнивание на мобиле под названием, на десктопе справа (уже частично есть).
3. Чипы стека: единый размер, перенос строк чипов аккуратный; ховер опционален.
4. Разделение двух продуктов JustDo (CRM vs WMS) визуально не обязательно — буллеты уже
   разделяют; не усложнять.

## Критерии приёмки
- Обе карточки читаемы на 375px: ничего не вылезает, чипы переносятся.
- Ссылки компаний открываются в новой вкладке (rel="noopener" уже стоит).
- `npm run build` + `npm run check` зелёные; скриншоты.

## Идеи вне скоупа
- Логотипы компаний, вертикальный таймлайн с линией.

# T10 — Полировка и finish gate

## Цель
Финальный проход перед публикацией: анимации появления, доступность, визуальный аудит,
чистая сборка. После этой задачи сайт считается готовым к пушу.

## Шаги
1. Появление секций при скролле: лёгкий fade+translateY через IntersectionObserver,
   один маленький inline-скрипт; `prefers-reduced-motion` отключает. НЕ делать, если
   после T02–T08 страница и так смотрится цельно — решить по факту.
2. Доступность: прогон по клавиатуре (tab во всех интерактивных), контрасты AA,
   alt-тексты, aria-label навигаций (частично стоит).
3. Lighthouse (через preview): Performance ≥95, Accessibility ≥95 на обеих локалях.
4. Визуальный аудит anti-ui-slop: сравнить с референсом ziit.app — единая сетка, ритм,
   никаких разнобойных радиусов/теней; всё из токенов.
5. Мета-финал: title/description обеих локалей перечитать глазами по stop-slop.
6. Прогнать полный цикл: `npm run build`, `npm run check`, скриншоты 375/768/1280 RU+EN.

## Критерии приёмки
- Все проверки выше зелёные; список найденных и исправленных проблем приложен к коммиту.
- Владелец дал добро на публикацию → можно пушить (пуш только по явной просьбе).

## Идеи вне скоупа
- Новые секции, блог, тёмные паттерны «ещё чуть-чуть улучшить» без согласия.

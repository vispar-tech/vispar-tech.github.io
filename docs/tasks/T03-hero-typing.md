# T03 — Hero: терминальный typing

## Цель
Фирменный первый экран: терминальный мотив, ротация ролей typing-эффектом, композиция.

## Вход
- Контент: `hero` в `src/content/{ru,en}.ts` (`prompt`, `roles[]`, CTA).
- Токены: акцент `--accent`, моно `--font-mono`.
- Скиллы: `anti-ui-slop` + `ui-design`, референс ziit.app.

## Шаги
1. Ротация строк `roles[]`: vanilla `<script>` внутри Hero.astro (печать посимвольно,
   пауза, стирание, следующая строка; мигающий курсор `_` цветом акцента).
2. Уважать `prefers-reduced-motion`: без анимации — просто первая роль статично.
3. Композиция по решению агента в рамках токенов: можно терминальное окно-рамка вокруг
   `$ whoami`-блока, но без перегруза. Аватар остаётся.
4. Мобайл: размеры clamp(), CTA кнопки на всю ширину при <480px.

## Критерии приёмки
- Эффект работает, курсор мигает, роли ротируются; RU и EN роли берутся из контента.
- При reduced-motion анимации нет, контент полностью читаем.
- Скриншоты 375px/1280px; `npm run build` + `npm run check` зелёные.

# T04 — About: типографика и цифры

## Цель
Секция «Обо мне»: читаемые абзацы, выразительные цифры-статы без украшательства.

## Вход
Контент: `about` в `src/content/{ru,en}.ts`. Текущая заглушка `About.astro`.

## Шаги
1. Типографская сетка: абзацы `max-width` ~65ch, межстрочный 1.6+, отступы по ритму.
2. Статы: крупные моноширинные значения акцентным цветом, подписи вторичным текстом.
   Ховер-эффекты не обязательны — это не интерактив.
3. Проверить переносы длинных русских слов на 375px (`overflow-wrap` уже в base.scss).

## Критерии приёмки
- Абзацы читаются комфортно на 375px и 1280px; цифры заметны, но не кричат.
- Никакого текста вне контент-файлов.
- `npm run build` + `npm run check` зелёные; скриншоты приложены.

## Идеи вне скоупа
- Фото рабочего места, галереи, таймлайн карьеры (это в Experience).

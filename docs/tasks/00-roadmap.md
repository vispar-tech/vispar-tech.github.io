## Правила прохождения

- Каждая задача = отдельный коммит (conventional-commit) или серия коммитов.
- UI-задачи (T02–T08, T10): перед кодом посмотреть 2–3 референса через `ui-radar`,
  держать стиль ziit.app; после — скриншоты 375px/1280px через playwright MCP.
- Тексты менять только в `src/content/{ru,en}.ts`, потом прогонять `stop-slop`.
- Не расширять скоуп задачи. Идеи «на будущее» записывать в конец файла задачи в раздел
  «Идеи вне скоупа» — не реализовывать.

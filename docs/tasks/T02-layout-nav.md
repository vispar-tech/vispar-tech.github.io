# T02 — Layout, навигация, переключатель языков

## Цель
Довести каркас страницы до продакшн-уровня: шапка, навигация по секциям, переключатель
RU/EN, адаптив. База уже стоит (Layout/Header/Footer/LanguageSwitcher) — полируй, не переписывай.

## Вход
- `src/layouts/Layout.astro`, `src/components/{Header,Footer,LanguageSwitcher}.astro`.
- Спек: `docs/spec.md` (визуальный язык).

## Шаги
1. Мобильная навигация: на <760px меню скрыто. Решение агента: минимальный раскрывающийся
   список или компактная строка якорей; без JS если возможно (`<details>` допустим).
2. Активное состояние якорной ссылки при скролле — только если решается без библиотек;
   иначе пропустить (вне скоупа тянуть IntersectionObserver-обвязку).
3. LanguageSwitcher должен вести на эквивалентную страницу той же позиции прокрутки,
   если дёшево; минимум — корректные `/` ↔ `/en/`.
4. Фокус-стили для всех интерактивных элементов (видимый focus ring акцентом).
5. Skip-link «к содержимому» для клавиатуры.

## Критерии приёмки
- Навигация работает на 375px и 1280px; фокус виден; skip-link работает.
- Переключение языков туда и обратно корректно.
- `npm run build` + `npm run check` зелёные.

## Идеи вне скоупа
- Тема-переключатель light/dark (только dark по спеку).

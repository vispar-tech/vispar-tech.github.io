---
description: Подготовить тексты коммитов по незаакоммиченному диффу
---

Собери незаакоммиченные изменения (`git status --short`, `git diff`), раздели на
логические единицы и для каждой выдай готовую команду:

```bash
git commit -m "<type>(<scope>): :<gitmoji>: <описание ≤70 символов>" -- <files>
```

Правила: сообщения на английском, императив, без точки в конце, gitmoji-шорткод с двойными
двоеточиями после типа. Новые файлы сначала `git add <файлы>`. Сам команды не исполняй —
исполняет владелец.
